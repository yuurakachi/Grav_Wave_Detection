# Grav_Wave_Detection
Este proyecto explora la combinación de técnicas de Análisis Topológico de Datos (TDA) y Redes Neuronales Convolucionales (CNN) para mejorar la detección de ondas gravitacionales. Utilizando datos sintéticos y métodos como Sliding Window Embedding, se logra un análisis más eficiente y robusto frente al ruido, lo que mejora la identificación de señales generadas por eventos cósmicos como la fusión de agujeros negros. El enfoque también contribuye a la privacidad y seguridad de los datos, y facilita la visualización de la dinámica temporal de las señales.
